# Stellaris Revived Project

> This page is maintained as part of the **Stellaris Revived Project**, which aims to preserve and keep abandoned community mods compatible with the latest versions of Stellaris.

## About

This project aims to preserve and keep abandoned community mods compatible with the latest versions of Stellaris. The primary focus is Quality of Life mods and minor mods that can be maintained by one person of a small team within a reasonable amount of time.
